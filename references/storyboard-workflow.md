# 分镜工作流

## 分镜字段

每个镜头至少包含：

```text
shot_id:
timecode:
duration:
story_function:
shot_size:
camera_angle:
camera_motion:
character_anchor:
action:
performance:
environment:
lighting:
product_state:
dialogue_or_vo:
sfx_or_music:
transition:
continuity_notes:
```

## 镜头设计原则

- 一个镜头承担一个主要叙事任务。
- 一个镜头尽量只有一个主动作；复杂动作拆镜头。
- 反转镜头前至少保留一个视觉伏笔镜头。
- 人物外貌、发型、服装、年龄、体型写成可重复锚点。
- 产品第一次关键出现前，不允许模型随意生成相似替代品。
- 需要读懂的文字不要放在快速运动镜头里。

## 推荐景别节奏

- Hook：中近景/特写/强行为瞬间。
- 建立关系：中景或双人景。
- 升级：中景 + 反应特写交替。
- 反转：先给信息特写，再给人物反应。
- Packshot：稳定、干净、产品优先。

## 连续性

每镜写清上一镜状态遗留：

- 人物手里拿着什么；
- 产品是否已打开/喝过/使用过；
- 衣服是否湿、脏、破；
- 场景中重要道具位置；
- 时间是白天/夜晚、天气与光线。
