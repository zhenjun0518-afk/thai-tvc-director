# 创意路由

目标：根据产品、广告目标、时长与受众，选择最适合的泰式叙事机制，而不是随机套“搞笑”或“催泪”。

## 先定义四个变量

- **Audience**：谁在看？
- **Tension**：他们生活里最具体的麻烦/欲望是什么？
- **Product Role**：产品在事件中能做什么？
- **Payoff**：最后让观众笑、心酸、释然、惊讶还是想尝试？

## 路由建议

### absurd_comedy
适合：饮料、零食、清洁、日用品、便利产品、社交传播。

结构：小问题 → 过度认真 → 连锁升级 → 观众误判 → 极端但合理的最后一步 → 产品回扣。

硬规则：荒诞来自人物认真对待小事，不是随机发疯。

### emotional_twist
适合：家庭、生活服务、保险/公益类概念、礼赠、食品、陪伴型产品。

结构：关系建立 → 缺失/误解 → 行动积累 → 观众形成错误理解 → 揭示真正动机 → 产品成为关系证据或行动媒介。

硬规则：不要靠疾病、死亡、贫困做廉价煽情；若使用高情绪议题，必须与产品和人物真实关系紧密相关。

### warm_family
适合：食品、饮料、家居、日用品、亲子、节日。

结构：家庭小摩擦 → 嘴硬/代际差异 → 微小行动 → 情绪回暖 → 产品成为日常连接点。

### humanity
适合：品牌建设、服务、长期主义主题。

结构：普通人选择 → 小善意/尊严 → 不求回报 → 迟到的回响 → 产品或品牌价值自然出现。

### suspense_reveal
适合：功能明确的科技、清洁、工具、便利产品。

结构：异常现象 → 错误解释 → 线索递增 → 真相揭示 → 产品功能完成解释。

### romantic
适合：香氛、饮料、礼赠、时尚、生活方式产品。

结构：人物目标 → 误会/错过 → 产品触发行动 → 关系推进 → 轻巧回扣。

### product_demo_story
适合：需要清楚展示功能的产品。

结构：真实问题 → 尝试失败 → 产品介入 → 功能演示 → 戏剧性结果 → 品牌收束。

## 自动选择评分

给每条路线在 1–5 分评估：

1. 与产品角色的天然契合度
2. 与 Campaign Goal 的契合度
3. 目标时长内可完整讲清的程度
4. 反转或情绪回报强度
5. AI 视频可生成性

选择总分最高路线。若最高分与次高分差 < 2，可在 `concepts` 模式同时给两条不同方向。
