# 视频模型适配

本文件提供提示词组织策略，不承诺模型当前版本的具体功能。用户明确指定模型时，优先遵循用户实际可用界面与参数。

## auto

输出模型无关描述：单镜 3–8 秒、完整主体锚点、明确起止动作、摄影机、结束状态和禁止项。

## Seedance

- 强调时间顺序、动作起止、镜头连续性。
- 长片优先分镜生成再剪辑。
- 产品参考图存在时，反复强调 packaging consistency / no label drift。

## Veo

- 适合写清场景、对白/环境声意图、摄影语言和时间节奏。
- 不把字幕文字准确性委托给模型。

## Sora

- 用自然语言描述完整可视事件与摄影逻辑。
- 避免在一个镜头中塞多个互相冲突的镜头运动和时间跳跃。

## Kling

- 图生视频优先给明确人物动作幅度、镜头运动和首帧/尾帧状态。
- 产品镜头避免大幅旋转导致标签漂移。

## Higgsfield

- 当使用运镜/广告模板能力时，先锁定产品视觉，再添加摄影运动。
- 不为了炫技选择破坏产品可读性的镜头运动。

## 通用降级策略

若模型无法稳定完成一个镜头：

1. 减少动作；
2. 锁镜头；
3. 拆成两个镜头；
4. 使用静态产品 Packshot + 微运动；
5. 精确文字后期完成。
