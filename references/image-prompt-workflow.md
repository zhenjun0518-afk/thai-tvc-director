# 生图 Prompt 工作流

目标：为每个镜头生成稳定、可继续用于图生视频的关键帧图。

## 顺序

1. 角色锚点
2. 产品锚点
3. 当前动作瞬间
4. 场景与空间关系
5. 景别与机位
6. 光线与色调
7. 表演与情绪
8. 画幅与安全区
9. 禁止项

## 模板

```text
【Shot XX 生图 Prompt】
角色：完整重复角色锚点。
产品：完整重复产品锚点与当前状态。
画面：描述这一镜静态瞬间，不写时间过程。
构图：景别、角度、主体位置、前中后景。
环境：地点、时间、关键道具。
光线：主光、环境光、反射、色温。
表演：眼神、嘴角、姿态、手势。
商业质感：真实 TVC 摄影、自然皮肤、真实材质、克制调色。
安全：精确品牌文字与长中文后期叠加；不要生成额外 Logo。
负面：no extra fingers, no duplicate product, no deformed packaging, no random text, no watermark.
```

## 关键原则

- 不用“与上一镜相同”代替角色描述。
- 产品图存在时，不改变包装形态来“美化”。
- 情绪镜头优先自然反应，不做夸张 meme 表情。
- Packshot 可单独生成产品静帧，再用于视频模型做微运动。
