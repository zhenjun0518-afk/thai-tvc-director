# 视频 Prompt 工作流

## Prompt 顺序

`主体 → 初始状态 → 动作 → 场景 → 摄影机 → 光线 → 表演 → 节奏 → 声音建议 → 一致性 → 禁止项`

## 单镜模板

```text
【Shot XX 视频 Prompt】
时长：4 秒。
主体：完整角色锚点 + 完整产品锚点。
初始状态：人物与产品在第一帧的位置和状态。
动作：只描述 1–2 个连续可见动作，给出起点与终点。
场景：空间、背景活动、道具。
摄影机：镜头焦段感、机位、推拉摇移或 locked camera。
光线：自然光/室内光、主色温、反射与阴影。
表演：微表情、停顿、视线方向、反应速度。
节奏：正常 / 紧张 / 喜剧停顿 / 反转后留白。
结束状态：镜头最后一帧必须达到的状态，便于剪辑下一镜。
一致性：人物、服装、产品包装不得变化。
禁止：no morphing, no extra characters, no duplicate product, no label drift, no random text, no sudden costume change, no camera teleport.
```

## Quick 模式 Master Prompt

只要完整提示词时，也必须包含：

- 总时长和比例；
- 一句话故事；
- 时间段动作；
- 主角固定外貌；
- 产品固定外观；
- 镜头与光线；
- 情绪与反转；
- Packshot；
- Negative Constraints。

30 秒以上即使给 Master Prompt，也建议附逐镜 Prompt，因为长时长模型稳定性通常低于短镜头生成后剪辑。

## 时间与动作

- 3–5 秒镜头：一个清楚动作最佳。
- 5–8 秒镜头：最多两个连续动作。
- 人物从坐到站、走到门口、拿产品、打开、喝下、转头、说话等若同时发生，应拆镜。
- 反转镜头至少留 0.5–1 秒让观众读取信息。
