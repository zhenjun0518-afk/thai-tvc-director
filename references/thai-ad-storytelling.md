# 泰式广告叙事 DNA

“泰式感”不是地理符号，而是叙事节奏与人物观察。

## 核心结构

```text
普通生活
→ 非常具体的小人物
→ 一个极小但真实的欲望/麻烦
→ 角色认真对待
→ 问题不断升级
→ 观众被引向错误解释
→ 前面埋下的细节突然重组
→ 真相 / 反转
→ 产品进入因果链
→ 品牌情绪或第二次轻反转
```

## 人物原则

- 主角不是“广告演员”，而像真实生活里会遇到的人。
- 给人物一个可被理解的小目标：不丢脸、想省事、想被看见、想照顾家人、想追回关系、想证明自己。
- 配角不是工具人，至少有一个可识别态度或反应。
- 喜剧靠认真、误会、节奏和反应，不靠大喊大叫。

## 反转规则

好的反转满足：

1. 前文有至少 2 个可回看的伏笔；
2. 反转后观众能重新理解前面的行为；
3. 不依赖突然出现的新人物/新设定；
4. 与产品角色产生因果关系；
5. 不牺牲品牌可信度。

## 两段式反转

适合 30 秒以上：

- 第一次反转：解释人物真正动机；
- 第二次轻反转：用产品、Packshot 或一句文案把情绪再翻一次。

第二次反转不应推翻前面故事，只负责留下记忆点。

## 情绪曲线

### 喜剧
正常 → 奇怪 → 更奇怪 → 极度认真 → 揭秘 → 爆点 → 产品。

### 温情
轻松 → 小摩擦 → 失落 → 行动 → 误解 → 理解 → 产品/品牌余味。

### 悬疑
异常 → 线索 → 紧张 → 错误答案 → 真相 → 功能回扣。

## 禁止项

- 把“泰国广告”简化成夸张表情。
- 为了泰国感强塞寺庙、僧侣、嘟嘟车或口音。
- 先拍完整微电影，最后 2 秒才硬塞产品。
- 为了催泪随意使用重病、死亡、贫困。
- 反转完全依赖旁白最后一句解释。
