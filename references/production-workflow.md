# Director / Production 工作流

## 1. 建立 Brief

至少解析：产品、目标时长、画幅、目标受众、Campaign Goal、核心卖点、目标视频模型、语言、叙事偏好。

未提供时的默认：30 秒、16:9、模型无关、中文输出、一个核心卖点。

## 2. 产品 DNA

读取 `product-analysis.md`。如果输入图与用户描述冲突，以用户明确说明为最高优先；视觉细节以图为准。

## 3. 一句话广告任务

用一句话写清：

> 让【受众】在【具体场景/情绪】中感受到【产品核心价值】，最终记住【品牌印象】。

## 4. 人性洞察

洞察不是“大家都需要方便”，而是更具体：

- 明明很在乎，却装作不在乎；
- 为了不丢脸，会把小事越搞越大；
- 想省一分钟，结果浪费半小时；
- 家人真正表达关心时常常不说“我爱你”；
- 人会为了被认可做出很笨但真诚的事。

## 5. 选择故事路线

读取 `creative-routing.md` 和 `thai-ad-storytelling.md`。输出：

- 选中路线；
- 为什么适合产品；
- 产品在剧情中的角色；
- 反转机制；
- 结尾情绪。

## 6. 剧本

按秒写事件而非散文。30 秒示例节奏：

- 0–3s Hook
- 3–8s 人物与目标
- 8–15s 问题升级
- 15–22s 误导/最高点
- 22–27s 反转 + 产品回扣
- 27–30s Packshot + tagline

对白要短，人物能靠动作表达的就不要旁白解释。

## 7. 分镜

读取 `storyboard-workflow.md`。每镜必须有明确叙事功能，且单镜主要动作不超过 1–2 个。

## 8. 生图与视频 Prompt

读取：

- `image-prompt-workflow.md`
- `video-prompt-workflow.md`
- `product-consistency.md`
- `model-adapters.md`（如指定模型）

每镜 Prompt 自包含。

## 9. 声音

读取 `sound-design.md`。声音不是补充，而是节奏工具。反转前后可通过环境音、音乐抽空、短停顿和 Foley 强化。

## 10. Packshot

最终 2–4 秒必须清楚回答：

- 这是什么产品？
- 核心价值是什么？
- 观众为什么此刻记得它？

长促销文字、价格、二维码等使用确定性后期层。

## 11. QC

读取 `quality-and-delivery.md`。若任一阻断项失败，先内部修正再交付。
